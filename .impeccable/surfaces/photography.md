# Photography direction — looking, closer

> Current direction — November 11, 2026: `fluid-gallery.md` supersedes the two-mode composition and no-WebGL/no-idle-loop statements below. Infinite atlas now joins Gallery wall and Contact sheet, using existing photographs with recycled coordinates, drag/wheel/keyboard exploration, zoom and the existing native viewer. WebGL/drift are optional: reduced motion, saved Effects off, software rendering and unavailable/lost graphics keep the wall/sheet. Shared day/night tokens in DESIGN.md supersede the old red palette. The 253-photo snapshot, source handling, descriptions, native links and complete-image viewer commitments remain.

MODE: Image-first archive, separate from the software portfolio.
THESIS: Give the photographs room as individual prints, with a compact contact sheet available when the visitor wants to scan the collection.
OWN-WORLD: Extend the incumbent Industrial Optical Monograph: deep navy, ice-blue utility text and rules, red signal, Anybody headings and Instrument Sans reading/control text. Keep the homepage’s existing projects, circuitry, lens and contact experience.
FORM: Compact identity/back navigation, “Looking, closer.” introduction, sticky gallery controls, a staggered full-ratio print wall and quiet copyright footer. Desktop prints use four columns initially, two to seven by Distance; every thirteenth print spans two columns. Contact sheet uses eight columns. Phones use two-column wall and four-column sheet with density hidden. Orientation filters retain the same local image set.
FIRST VIEWPORT: Identity, direct return to software, short archive statement, clear mode/filter controls, and the beginning of the photographic collection. Avoid a cover image that delays the archive.
STORY: Overview -> scan or change viewing distance -> open a complete photograph -> explore nearby images -> return to the same print.
SIGNATURE INTERACTION: A finite DOM image entrance measured from the selected print to its full-image stage. The resting view fits the complete photograph. Previous/next arrows, Left/Right keys and nearby thumbnails navigate the filtered set. Escape/Close restores the originating link’s focus. 2× zoom uses native overflow pan; touch swipe navigates only outside zoom.
MOTION: Opening uses 680ms, image changes 480ms. Hover perspective and optional supported CSS scroll drift add restrained print depth. CSS and JavaScript both consult reduced motion. No photography WebGL or idle animation loop. Closing is immediate in the inspected implementation; a reverse return flight is not claimed.
CONTENT: 253 user-supplied local JPEG exports from Pictures/Lightroom Saved Photos, including alternate edits and numbered duplicates; the shared Drive folder is an alternate source. Read originals only to create copies, never move or alter them; no stock/generated photography. CR3 and XMP files remain excluded. Correct orientation, strip EXIF/GPS, create 560px previews and maximum-2000px full-view WebP assets. Serve local static assets and public metadata only; no local filesystem paths, Drive URLs, keys or tokens. Verify the final HTML, metadata and asset counts agree.
UPDATES: Static snapshot. The user adds new JPEG exports in the local saved-photo folder (or shared Drive folder) and requests a sync; generate thumbnail/full asset, metadata record and prerendered figure together. Keep local originals in their existing folder.
RESEARCH: Tyler Mitchell’s density archive and Romain Laprade’s image index/pacing, both inspected in-browser; see RESEARCH.md. Reuse structural lessons, not their imagery, identity or code.
ACCESSIBILITY: Native full-image links without JavaScript, semantic controls and labels, aria-pressed layout states, native dialog focus, visible focus, keyboard arrows/Escape, status count and reduced motion. All 253 photographs have content-based image descriptions. Gallery links, the full-view image and nearby-thumbnail controls use those descriptions; display filenames remain visual metadata. Navigation, close and arrow controls use consistent inline SVG icons.
QUALITY BAR: Images remain the focus at wide and phone widths; no cropped full viewer, distorted print, hidden route back, horizontal page overflow or motion-dependent access. Verify final HTML count, assets and metadata agree before publishing; do not claim completed checks from the temporary import.
