# Theme system — shared day and CobaltSky materials

MODE: Experience. Authorized revision of the shared portfolio and photography materials; supersedes the earlier lime hero candidate and navy/red interface palette.
THESIS: Keep the editorial optical identity and factual software evidence while making day/night materials, expressive live text and direct image comparison feel like one coherent experience.
OWN-WORLD: Light blue, cream and a hint of burnt orange by day; CobaltSky navy, warm cream and sky blue with peach-orange feedback by night. Anybody display and Instrument Sans reading/control text remain. Theme roles and exact values are normative in DESIGN.md and theme.css.
FORM: Persistent native sliding checkbox switch in both routes. The selected palette reaches the hero, loader, blue ribbon, circuit field, rounded project selector, case studies, About, contact, dialogs and archive controls. Preserve existing layout boxes and real assets.
STATE: sv-theme persists explicit selection. Early initialization uses the saved valid theme, otherwise OS preference. Unsaved OS changes and cross-tab storage changes update state. Checked role=switch means Dark theme. Theme application emits themechange and updates browser chrome.
SIGNATURE INTERACTION: Switch-centered radial View Transition (760ms) when supported, reduced motion is absent and Effects are enabled; immediate fallback otherwise. Effects off also applies theme changes immediately. ReactBits-inspired native split/blur words animate the unchanged hero and section titles; native scroll resolves case statements. Aceternity-inspired comparison adds bounded elastic bend, slight blur and finite sparks to direct dragging while retaining the native range, Zoom 4×, X/Y controls and Enlarge.
MOTION: Text and comparison JS feedback consult reduced motion and Effects; the hero also stops offscreen/hidden and retains static fallback. Native comparison and readable case text remain usable without motion. No React dependency, new backend, build step, invented copy or replacement assets.
PHOTOGRAPHY: Apply the same selected roles to archive identity, rules, toolbar, modes, density, captions, focus and viewer. Preserve the separate image-first route, local 253-photo snapshot, full-ratio wall, contact sheet, filters, native links/dialog, complete-image rest view and keyboard/touch controls recorded in photography.md. The older surface brief's navy/red palette sentence is historical; this shared-theme direction supersedes it.
QUALITY BAR: Review both palettes at desktop and phone widths, keyboard switch/range operation, persisted navigation, first-visit OS preference, reduced-motion/static states and image comparison at zoom. Claims here describe inspected source; browser acceptance belongs to the final review.
